**修复版：补丁工具的 asar 数据区偏移与完整性校验。已装 0.3.0 的用户不需要重新打补丁。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/ZCodeTpsBadge/issues/new/choose) 反馈 —— 请附上 ZCode 版本、补丁运行输出与徽标截图。

## 本版内容

**补丁工具**

- 修复 数据区偏移 —— 基准从 `18 + jsonSize` 改为 `16 + align4(jsonSize)`；旧写法只在头部 JSON 长度余 2 时碰巧正确，余 1 / 3 时会错 1 字节，把错位内容当成 preload 写入并改掉 integrity —— 表现为 ZCode 白屏或启动崩溃。ZCode 升级后重新应用补丁时生效。
- 新增 完整性校验 —— 读出的原始字节与 asar 头部记录的 SHA-256 逐块比对，不一致直接失败退出，不再把错位内容写出去。
- 调整 落盘 —— asar 头部写完后 `fsync`，缩小断电时只写一半的窗口。

**文档**

- 调整 收尾 —— 清理补丁中间物与预览生成物，文档与 0.3.0 的实现对齐。

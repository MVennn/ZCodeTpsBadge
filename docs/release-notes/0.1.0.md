# 0.1.0 — 2026-10-21

首个公开版本：在 ZCode 桌面版输入框工具条里显示 tok/s 徽标。

## 新增

- 胶囊徽标：流式输出显示 `42.1 tok/s`，空闲显示 `— tok/s`。
- 位置：输入框底部工具条、用量 / 模型选择器左侧；窗口缩放时随工具条重排并三档收缩。
- 悬停统计卡：当前 / 平均 / 最高 / 最低 / 累计 tokens / 活跃时长。
- 统计范围只认聊天区助手输出；思考文本与工具调用阶段也会显示速度。
- 侧边栏、用户消息、后台终端不计入；工具块内输出同样计入（估算值）。
- 深 / 浅主题自动适配，颜色使用 ZCode 主题变量。
- 备用 CDP 注入模式，不修改 `app.asar`。

## 修复

- 修复启动时先出现在右下角再跳到工具条的问题：工具条出现前不注入。
- 修复 markdown 重渲染导致重复计数：按聊天区根 token 总量算增量。
- 修复停止输出后数字久久不归零：最后一次文本增长后 1.8 秒归零。

## 升级注意

- 本项目非官方，与 ZCode 官方无隶属、合作或授权关系。
- 会修改本地 ZCode 安装目录的 `app.asar`；ZCode 升级会覆盖补丁，需要重新运行
  `tools/apply.cmd`。
- 打完补丁必须从托盘完全退出 ZCode 再启动；点窗口 X 只是收进托盘。
- 徽标数值是按页面文本估算的，不是模型返回的精确 usage。

## 验证

- 本地夹具验证：侧边栏 / 用户消息 / 工具输出 / 历史消息均不计数；
  助手流式输出显示数值，停止 2.2 秒后回到 `—`。
- 900 / 600 / 420 三种窗口宽度下徽标都在工具条内，宽度 77 / 32 / 27px。
- 悬停卡在徽标上方居中，显示当前 / 平均 / 最高 / 最低 / 累计 / 活跃。
- ZCode 内实际效果需完全退出再启动后确认；未验证的版本会在 Issue 中说明。

## 已知限制

- 只在 Windows + ZCode 桌面版验证。
- 统计依赖聊天区 DOM；ZCode 大版本升级后可能需要更新选择器。
- 徽标数值受渲染节奏影响，适合观察趋势，不适合精确 benchmark。

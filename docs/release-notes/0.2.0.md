**计数改从 ZCode 内部事件流取真实增量：思考行折叠时也能显示速度。**

## 本版内容

**徽标**

- 新增 思考折叠测速 —— 徽标；思考（推理）行折叠时也显示 tok/s，不再停在 `—`。
- 调整 计数来源 —— 徽标；优先取 ZCode 内部事件流的字符增量（助手正文 / 思考 / 工具参数），页面文本估算降级为 4 秒无事件时的兜底。
- 调整 工具调用计数 —— 徽标；工具调用的参数流也计入速度，参数很长时数值会偏高。

**补丁**

- 调整 补丁内容 —— 需重新运行 `tools/apply.cmd`；本次补丁新增事件层 tap，旧补丁不会自动更新。

---

需要 Windows + ZCode 桌面版；补丁会修改本地 `app.asar`，ZCode 升级后需重新运行
`tools/apply.cmd`。安装步骤见 [README](https://github.com/MVennn/ZCodeTpsBadge#安装)。

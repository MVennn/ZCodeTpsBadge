# 0.2.0 — 2026-10-21

计数改从事件层拿真实增量：思考行折叠时也能显示速度了。

## 变更

- 徽标计数改为双路：主路径从 ZCode 内部事件流拿真实的字符增量
  （助手正文 / 思考 / 工具参数），页面文本估算降级为兜底。
- **思考（推理）行折叠时也能测速** —— 这是 0.1.0 的最大盲区：
  折叠时思考正文不进页面，原先只能显示 `—`。
- 徽标数值仍是估算（字符 × 系数），不是模型返回的精确 usage；
  但增量的来源从「页面可见文本」升级为「真实数据流」。

## 升级注意

- 从托盘完全退出 ZCode，重新运行 `tools/apply.cmd`（补丁内容变了，必须重建）。
- ZCode 升级会覆盖 `app.asar`，补丁需要重新应用。
- 本项目非官方，与 ZCode 官方无隶属、合作或授权关系。
- ZCode 大版本若改动内部数据格式，事件计数会静默失效并自动回退页面估算
  （表现为思考折叠阶段又开始显示 `—`，其余照旧）。

## 验证

- 解码器对合成字节流 round-trip 全通过（含噪声帧、截断帧不崩溃、不误计数）。
- 合成消息流量下，tap 输出正确的每行字符增量。
- 补丁三层验证通过：干跑、外部 preload 语法、Electron 实际解析到外部文件。
- **真机效果需完全重启 ZCode 后确认**（发版环境无法重启宿主，未验证已明说）。

## 已知限制

- 事件计数依赖 ZCode 内部数据格式；ZCode 升级可能使主路径暂时失效（自动兜底）。
- 工具调用阶段的参数流也计入速度；工具参数很长时速度可能偏高。
- 徽标数值适合观察趋势，不适合做精确 benchmark。

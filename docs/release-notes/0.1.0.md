**首个公开版：在 ZCode 桌面版输入框工具条里显示 tok/s 徽标，悬停看当前 / 平均 / 最高 / 最低 / 累计 / 活跃。**

## 本版内容

**徽标**

- 新增 速度徽标 —— 输入框底部工具条、用量与模型选择器左侧；流式输出显示 `42.1 tok/s`，空闲显示 `— tok/s`。
- 新增 响应式收缩 —— 徽标；窗口变窄时依次隐藏圆点与单位、缩小字号，三档都留在工具条内。
- 新增 主题适配 —— 徽标；深 / 浅主题跟随 ZCode 主题变量。

**悬停统计卡**

- 新增 统计卡 —— 悬停徽标；显示当前 / 平均 / 最高 / 最低 / 累计 tokens / 活跃时长。
- 调整 统计范围 —— 统计卡；只统计聊天区助手输出，侧边栏、用户消息、后台终端不计入。

**安装**

- 新增 补丁安装 —— `tools/apply.cmd`；修改 `app.asar` 后在输入框工具条显示徽标。
- 新增 备用模式 —— `tools/launch-zcode-tps.cmd`；CDP 注入，不修改 `app.asar`。

**修复**

- 修复 思考与工具调用计数 —— 徽标；思考文本与工具调用块计入速度，仅排除推理标签、状态标签与后台终端 / 开发者工具。
- 修复 侧边栏计数 —— 打开侧边栏时徽标不再跳数字。
- 修复 徽标不计数 —— 不再依赖真实聊天 DOM 里不总存在的角色属性。
- 修复 重复计数 —— markdown 重渲染不再把已有内容再算一遍。
- 修复 空闲不归零 —— 停止输出 1.8 秒后回到 `—`。
- 修复 启动位置 —— 不再先出现在右下角再跳到工具条。

---

需要 Windows + ZCode 桌面版；补丁会修改本地 `app.asar`，ZCode 升级后需重新运行
`tools/apply.cmd`。安装步骤见 [README](https://github.com/MVennn/ZCodeTpsBadge#安装)。

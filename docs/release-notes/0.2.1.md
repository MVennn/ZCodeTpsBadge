# 0.2.1 — 2026-10-21

修复挂后台后统计卡平均速度被稀释的问题。

## 修复

- 会话长时间挂在后台再回来，统计卡的「平均」会掉到个位数（例如 7.1 tok/s）、
  「活跃」暴涨、「最高」出现几千的假尖峰。
- 现在：后台期间不结算、不计入活跃时长；回到前台后积压的增量按之前的
  真实速率摊还进累计与活跃；最高 / 最低不再记录这类构造出来的瞬时值。
- 悬停卡里的「平均 / 最高 / 最低」现在反映的是**真实可见流式时段**的速度。

## 升级注意

- 从托盘完全退出 ZCode，重新运行 `tools/apply.cmd`（补丁内容变了，必须重建）。
- ZCode 升级会覆盖 `app.asar`，补丁需要重新应用。
- 本项目非官方，与 ZCode 官方无隶属、合作或授权关系。
- ZCode 大版本若改动内部数据格式，事件计数会静默失效并自动回退页面估算。

## 验证

- 场景仿真通过：可见流式 → 后台 25 分钟持续产出 → 回前台，
  修复后平均 / 最高恢复真实值，累计不丢。
- 补丁三层验证通过（干跑、外部 preload 语法、Electron 实际解析）。
- **真机效果需完全重启 ZCode 后确认**（发版环境无法重启宿主，未验证已明说）。

## 已知限制

- 事件计数依赖 ZCode 内部数据格式；ZCode 升级可能使主路径暂时失效（自动兜底）。
- 工具调用阶段的参数流也计入速度；工具参数很长时速度可能偏高。
- 徽标数值适合观察趋势，不适合做精确 benchmark。

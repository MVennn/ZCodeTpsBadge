**tok/s 改为开发者工具同源数据：每轮请求完成后显示真实 usage，思考也计入。**

## 本版内容

**徽标**

- 调整 速度数值 —— 输入框底部工具条；改为每个完成的主轮请求显示该请求的真实 tok/s，与开发者工具「Token 调试」同一行一致。
- 修复 思考 tokens —— 折叠思考时不再漏计；输出 / 思考 tokens 直接来自模型 usage。
- 修复 异常速度 —— 开发者工具偶发的 6 万 tok/s（388 tok / 6ms）不再带偏平均 / 最高；异常轮次显示 `—`。
- 调整 生成中状态 —— 圆点脉冲，数字保持上一轮；不再逐秒跳动。
- 修复 假数字 —— 删除按页面字符估算的旧统计，页面文本、工具输出、历史消息不再影响读数。

**悬停统计卡**

- 调整 内容 —— 改为本轮速度 / 平均速度 / 最高速度 / 最低速度 / 输出 / 思考 / 输入 / 缓存命中 / 生成耗时 / 会话请求 / 累计输入 / 累计命中 / 状态。
- 移除 平均命中 —— 悬停卡不再重复显示；开发者工具摘要里已有。
- 移除 旧统计 —— 当前 / 平均 / 最高 / 最低 / 累计 / 活跃 六行不再显示。

**排错**

- 修复 启动页 —— 0.3.0 初版应用后可能卡在启动页；已改为等应用完成端口握手后再读取数据。
- 新增 数据源状态 —— 读不到开发者工具数据时显示「数据源不可用」，不显示估算值。

**补丁**

- 调整 补丁内容 —— 需重新运行 `tools/apply.cmd`；本次补丁内容有变，旧补丁不会自动更新。

## 本版内容

**悬停统计卡**

- 修复 最高 —— 悬停徽标；工具输出、整行刷新等大块内容不再被当成瞬时速度，最高不再跳到几千 / 一万。
- 修复 平均 / 累计 —— 悬停徽标；事件层与页面层交接时不再把同一段正文计两遍。
- 修复 当前 —— 输入框底部工具条；大块内容到达时数值不再闪出离谱的尖峰。

**徽标**

- 修复 思考速度 —— 输入框底部工具条；思考阶段也能看到当前速度与累计 token（事件层此前没有真正生效）。
- 修复 中文速度 —— 输入框底部工具条；事件层与页面层改用同一套中英文字符换算，中文读数不再偏低。

**补丁**

- 调整 补丁内容 —— 需重新运行 `tools/apply.cmd`；结算逻辑有变，旧补丁不会自动更新。
